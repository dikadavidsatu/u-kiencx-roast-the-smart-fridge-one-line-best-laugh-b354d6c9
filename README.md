# Roast the Smart Fridge: One Line, Best Laugh Wins

A one-line roast of the modern smart fridge — the $3,000 appliance with
an interior camera, a touchscreen, and a companion app that reports
your 2 a.m. snacking like it is filing paperwork. The program prints
exactly one line:

> My smart fridge texts me when I open it at 2 a.m., photographs the evidence, and snitches to an app — I paid $3,000 for a refrigerator and accidentally hired a parole officer for cheese.

## What it does

`main.ts` assembles the roast from named fragments (the surveillance
setup, the price tag, and the parole-officer punchline), runs it
through a small entry gate — exactly one line, no stray whitespace,
within the one-liner character budget — self-checks that the gate
rejects bad lines, and prints the roast as its only output. The output
is fully deterministic: no randomness, no clock, no network.

## How to run

```sh
node main.ts
```

Requires a Node.js version with TypeScript type stripping (Node 22.6+
with `--experimental-strip-types`, or Node 23.6+ / 24 out of the box).
No dependencies.
